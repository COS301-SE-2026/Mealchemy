Spacing and Shape

Spacing controls the distance between elements. Radius controls how rounded a component's corners are, helping users recognise buttons, cards, sheets, and tags consistently.

This is the spacing scale: each token is a reusable distance between interface elements. Small steps such as 4px and 8px separate tight items like icons and labels, while 24px and 32px create clearer breaks between cards, sections, and page groups.

Radius Scale

Small radius feels precise and compact. Medium radius is used for buttons and inputs. Larger radius softens cards and panels, while pill radius is reserved for tags and rounded actions.
