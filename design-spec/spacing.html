06 Layout & Spacing

Layout and Spacing

The layout system uses compact spacing, rounded surfaces, and flexible sections that stack cleanly from desktop-width previews down to mobile screens.

The screens uses 4, 8, 16, 24, and 32px. Component-specific values add 6, 10, 14, and 20px where tighter controls need them.

Responsive Layout

How screens adapt

Mealchemy is mobile-first. Larger screens add columns and wider content areas, while mobile screens stack sections into one readable column.

DesktopTwo-column content

Wide screens can show main content, supporting panels, and card rows side by side.

TabletReduced columns

Medium screens keep two-card groupings but reduce extra side content.

MobileSingle column

Small screens stack all cards, keep 20px page gutters, and keep navigation fixed at the bottom.

Desktop24 to 32px section spacing

More breathing room around grouped content.

Tablet16 to 24px gaps

Sections stay grouped while preserving scanability.

Mobile12 to 20px gutters

Content stacks vertically with full-width controls.
