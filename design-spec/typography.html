02 Typography

Typography system

Mealchemy uses two Google Fonts: Newsreader for expressive headings and Plus Jakarta Sans for clear interface text. The type scale stays compact, readable, and consistent across the product.

Display TypefaceNewsreader

Used for brand moments, page titles, and section headings.

Interface TypefacePlus Jakarta Sans

Used for body copy, forms, buttons, navigation, and labels.

Fallbacks & LicensingGoogle Fonts

Newsreader falls back to Georgia/serif. Plus Jakarta Sans falls back to Arial/system sans.

Font Families

Typefaces

Each font has a clear role. Serif type is reserved for prominent moments; sans type handles repeated UI reading.

Newsreader Elegant recipe headings.

Used for display, page titles, and section headings.

Plus Jakarta Sans Clear app content and controls.

Used for body copy, buttons, labels, forms, and navigation.

System sans fallback Fallback interface font.

Used only if Plus Jakarta Sans is unavailable.

CMU Serif MEALCHEMY

Reserved for static logo exports, not live app UI text.
