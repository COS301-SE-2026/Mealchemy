02 Typography

Typography system

Headings use Newsreader for a refined editorial tone. Body, buttons, labels, and interface text use Plus Jakarta Sans for clarity. Inter is a fallback for system UI, while CMU Serif is reserved for the static logo wordmark.

Hero wordmark sample

Mealchemy

Newsreader, 40px, weight 900, with tightened spacing for the splash and brand moments.

Font Families

Typefaces

Each typeface has a specific role so screens feel luxurious without becoming crowded or inconsistent.

Newsreader Elegant recipe headings.

Used for display, page titles, and section headings.

Plus Jakarta Sans Clear app content and controls.

Used for body copy, buttons, labels, forms, and navigation.

Inter Fallback interface font.

Used only as a fallback if Plus Jakarta Sans is unavailable.

CMU Serif MEALCHEMY

Reserved for the static wordmark and logo exports.
