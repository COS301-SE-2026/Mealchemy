01 Colour Palette

Core app palette and support tokens.

The main palette is small: maroon, gold, cream, near-black, muted grey, and semantic status colours. Support colours cover gradients, borders, dark mode, and selected states.

Core UI colours

Primary maroon, gold, cream surfaces, near-black text, muted grey, divider, and status colours are used across normal app screens.

Support tokens

Primary Light, Soft Gold, Muted Rose, Background Cream, Input Border, dark surfaces, overlays, and gradient endpoints support specific components or states.
